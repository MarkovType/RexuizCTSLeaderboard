# Rexuiz CTS Leaderboard

## What is it

This is a simple frontend for cts.rexuiz.com, showing records in a nice way.
It also saves the records in a database for historical reasons.

# How does it work

The application checks cts.rexuiz.com for any changes periodically, and creates a csv for historical reason, then store the new data in the database.

## Aliases

Rexuiz offers players the ability to have any nickname. As such, if you have records under different aliases, please ask for an alias merging in the Rexuiz discord server (#chat channel).
Alias merging will allow you to have your records under a same nickname, showing all your other aliases.
